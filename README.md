# GRC Audit Lab: NIST 800-53 Media Protection

This repository contains a hands-on GRC audit lab aligned with NIST SP 800-53 Rev. 5, focused on the Media Protection (MP-1 through MP-8) control family.

The project simulates a real-world control assessment using a publicly available System Security Plan (SSP) and fictionalized audit evidence to demonstrate how controls are evaluated, tested, and documented in practice.

## Controls Covered
- MP-1: Policy and Procedures
- MP-2: Media Access
- MP-3: Media Marking
- MP-4: Media Storage
- MP-5: Media Transport
- MP-6: Media Sanitization
- MP-7: Media Restrictions
- MP-8: Media Downgrading

## Files Included
- Control assessment and testing documentation
- Risk ratings and findings
- Remediation considerations
- Assessment using a public SSP reference

> ⚠️ No proprietary or client information is included. All materials are part of a simulated audit lab using public references and fictionalized data. 

This project demonstrates practical application of NIST 800-53 control assessment and audit methodology in a GRC context.
