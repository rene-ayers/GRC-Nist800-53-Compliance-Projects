# GRC Audit Lab: NIST 800-53 Media Protection

This repository contains a hands-on compliance project aligned with NIST SP 800-53, Rev. 5 — specifically covering the Media Protection (MP1 to MP8) family of controls. The document includes control-by-control assessments, audit evidence, risk ratings, and real-world remediation suggestions.

## 🔍 Controls Covered:
- MP-1: Policy and Procedures
- MP-2: Media Access
- MP-3: Media Marking
- MP-4: Media Storage
- MP-5: Media Transport
- MP-6: Media Sanitization
- MP-7: Media Restrictions
- MP-8: Media Downgrading

## 📁 Included:
- ✅ GRC audit spreadsheet (PDF)
- ✅ Risk scoring
- ✅ Findings and mitigations

This project demonstrates practical application of compliance frameworks in a simulated audit scenario.
